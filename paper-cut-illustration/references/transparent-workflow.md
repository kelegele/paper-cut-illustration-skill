# 透明 PNG：纯色底图 + 本地抠图

此流程不要求生图工具支持透明通道。脚本仅抠图，不负责把照片转换成插画。

## 1. 准备容易抠图的插画

先查看人物配色，选择与主体不冲突的高饱和背景色，常用 #00FF00 或 #FF00FF；不固定使用绿色。如果主体含绿色，优先考虑洋红色，反之亦然。暖白描边应连续，将人物与底色分隔。画面边缘保留可见背景，不让人物触边。

完整读取原始提示词后追加本次比例、主体范围及以下指令（替换颜色）：

> 本次最终交付透明 PNG，但本次生图只输出普通不透明的纯色底图。背景严格为均匀的 KEY_COLOR，无纹理、无渐变、无灯光变化、无阴影、无棋盘格，不将背景色反射到主体。保留人物内部的纸张层次与阴影，主体外缘保留连续窄暖白模切边。人物之间可见的背景空隙也使用相同背景色。保留画布边缘留白。此要求覆盖原文米色背景和背景投影要求，其余风格不变。

同时明确选定宽:高比例，覆盖原文竖版要求。多人合影且用户选择全部时，在独立补充指令中覆盖单人限定、保留角色数量和相对位置，不改写原文。

没有生图工具：保存并提供“完整原文 + 本次补充设置”文本，告诉用户将原图与全文交给自己使用的生图平台，并上传生成的纯色底图继续。不得只输出补充设置而遗漏原文。无需配置生图 API Key。用户已经提供合适的插画底图时直接进入抠图，不重新生图。

## 2. 执行脚本

依赖：uv、Pillow。脚本内置依赖声明，首次运行 uv 可能下载 Python/Pillow；后续有缓存可离线运行。无需生图接口、模型权重或 GPU。uv 不可用时说明依赖缺失，不能静默改用系统 Python。

在 skill 目录执行（从别处调用时使用脚本绝对路径；输入、输出路径可按项目实际位置替换）：

```powershell
uv run scripts/remove_background.py "input.png" "output/cutout.png" --key "#00FF00"
```

- 输出路径必须是新的 .png，脚本拒绝覆盖源图或已有文件。
- 默认 tolerance=35、feather=65，以 RGB 最大通道差判断背景并对邻近边缘进行近似去色污染，不是语义分割。
- 仅删除与画布边缘连通的背景区域，默认保留人物内部相同颜色。
- 封闭背景孔：查看图像，确认孔内坐标属于背景后增加 `--seed "x,y"`；可多次指定。坐标以实际像素尺寸为准，不是缩放预览坐标。禁止为“清得更干净”全局删除同色像素。
- 若结果有残边，可小幅调整 `--tolerance` / `--feather` 后输出到新文件；这些参数越大越容易侵蚀主体边缘，不应盲目增大。
- 棋盘格、复杂背景、背景色与主体混合或严重颜色污染不适合此脚本。优先要求新的纯色底图；需要通用分割模型时另行说明模型/下载依赖，不宣称本脚本能处理任意背景。

## 3. 检查与交付

脚本保持画布尺寸并输出 RGBA PNG，检查输出存在、含全透明像素且主体未被全部删除，打印 JSON 摘要。该检查不等于视觉质量通过。

对照原图核查角色完整性，核对实际宽高比；将成品在浅色和深色背景上预览，检查暖白边、背景空隙、残色、毛边及误删。可用 Pillow 临时合成预览，但预览不是交付文件，不覆盖透明成品。所有 Python 操作通过 uv。

修正失败时保留原始底图，说明具体问题；不把 RGB、全不透明 RGBA 或烘焙棋盘格图片称为透明 PNG。最多两次有针对性的脚本参数/seed 修正；仍不合格时说明需要更合适底图或分割方案，不无限重试。生图重试仍遵循 SKILL.md 的上限。

# 剪纸插画 Skill

本项目用于维护 `paper-cut-illustration` skill。用户已确认将前述流程做成 skill，并要求完整保留英文提示词；名称沿用项目的“插画”，不改为“人像”。

交付目录为 `paper-cut-illustration/`，包含 SKILL.md、原始提示词 references/original-prompt.txt 和界面元数据 agents/openai.yaml。原始提示词独立保存，执行时全文读取并传给图片工具；本次定制只追加指令，不修改原文。

执行流程：获取并查看原图、处理主体歧义、调用可用图片编辑工具、收集输出比例和背景、对照检查并交付一张插画。缺图时请求图片，缺工具时如实说明；半身照不补身体。当前原文针对人物，其他题材需明确适配，不更改原文。

不构建小红书离线小工具，不自动配置外部 API 或全局安装，不在无输入图片时生成测试图片。早先下载的小红书指南留作既有资料，不打入本 skill。

验证包括格式与引用检查、提示词五段原文核对，以及缺图、半身照、图片引用方式和无工具情境的行为复测。实际生图效果需要用户提供图片后验证。

输出选择：比例 1:1、4:3、16:9（宽:高），不设默认比例；背景为默认暖米色纯色、用户描述/色值指定的其他色、透明 PNG。生成前收集缺失选项；展示默认背景后只回复比例则采用默认背景。其他色缺颜色时补问。通过追加设置覆盖原文竖版和背景要求，原文不改。交付检查宽高和透明通道，无法验证时明示。
